Подключи свой GitHub

Альбом хранит фото в твоём GitHub-репо. Нужен fine-grained PAT (живёт у тебя в браузере, никуда не уходит).

  1. Зайди на github.com/settings/personal-access-tokens/new
  2. Resource owner: твой акк.
  3. Repository access: Only select repositories → выбери репо альбома.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate token, скопируй (`github_pat_...`).
